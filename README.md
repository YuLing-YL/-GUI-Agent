# 《羊了个羊》GUI Agent

一个**纯视觉**的 GUI Agent：截取游戏窗口画面 → 交给多模态大模型看棋盘 →
模型决定点哪块砖 → 程序把鼠标点下去 → 循环，直到本局结束。

不需要读取游戏内存、不需要注入、不需要修改游戏。

```
截图（游戏窗口） → 本地像素识别（可点砖块 / 遮挡检查 / 卡槽风险）
                → 候选清单交给视觉大模型 → 模型选一块砖并给出坐标
                → 本地安全校验（禁止道具 / 禁止点死） → 点击 → 下一轮
```

> **第一次用**：双击 `run.command`，在弹出的小窗口里填好你的模型服务，点「开始运行」。

---

## 一、它能做什么

- **全自动替你把这一局玩完**：看棋盘、判断哪块砖能点、点下去，全程不用你动手，鼠标自己动。
- **纯视觉决策**：只截游戏窗口的画面交给模型判断，符合正常玩家的操作方式。
- **本地安全兜底**：模型给出的坐标会再过一遍本地规则 —— 拒绝点被压住露不全的砖、
  拒绝点卡槽下方的道具区、卡槽快满时不会乱点把槽位堆死。
  模型的判断失误不会直接变成废操作。
- **每轮独立请求**：不累积历史截图和对话上下文，长时间运行内存不涨。
- **不在本地留下任何数据**：截图只活在内存和系统临时目录里、用完即删，
  没有日志文件、没有调试图、没有对局记录。跑完之后你的目录和跑之前一模一样。
- **随时能停**：鼠标甩到屏幕左上角，或按 `Ctrl+C`。
- **单实例保护**：防止不小心开两个进程互相抢鼠标。
- **默认全程本地推理**：游戏画面不出你的机器（除非你自己在窗口里填了云端 API）。
- **配置有窗口**：服务地址、模型 ID、API Key 都在启动窗口里填，不用改代码。

## 二、环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | **macOS**（必须）。窗口定位用的是 macOS 的 `Quartz` API，截图与鼠标控制也按 macOS 的方式实现 |
| Python | 3.11（实测 3.11.17），**需要自带 tkinter**（macOS 官方版和 conda 版都自带） |
| 模型服务 | 需要你自备一个**有视觉能力**的模型（LM Studio / vLLM / Ollama / 云端 API 均可），在启动窗口里填写 |
| 游戏 | 微信小游戏《羊了个羊》，窗口标题需含「羊了个羊」 |

## 三、安装并启动

### 1) 安装依赖

```bash
cd game
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2) 一键运行

**方式 A：双击 `run.command`**（推荐）

在 Finder 里双击即可。首次可能被 macOS 拦下，右键 → 打开。
它会自动挑一个带 tkinter 的 Python，然后弹出配置窗口。

**方式 B：终端运行**

```bash
python run.py
```

**方式 C：不开窗口，用上次保存的配置直接跑**

```bash
python run.py --no-gui
```

### 3) 授予系统权限（**最容易踩的坑**）

「系统设置 → 隐私与安全性」里，把**运行启动器的那个程序**
（终端 / iTerm / VS Code / python）同时加入并勾选：

- **屏幕录制** —— 不加：截图是黑的或只有桌面壁纸，模型看到纯黑 → 一直乱点或空转
- **辅助功能** —— 不加：`pyautogui` 无法移动鼠标 / 点击，画面看着正常但游戏毫无反应

改完权限**必须重启终端**才生效。判断是否生效：跑起来后看终端里有没有
`[窗口] 已找到游戏窗口：位置 (x, y)，大小 WxH`，以及 `[截图] 已裁剪到游戏窗口区域`。

### 4) 准备好游戏

1. 微信里打开小游戏《羊了个羊》，**进到可以开始点砖的关卡界面**；
2. 游戏窗口**保持可见、不要被其他窗口遮挡**；
3. 窗口位置随意（脚本每轮重新定位窗口），但别让标题栏被藏起来；
4. 建议把窗口固定在屏幕一角，运行期间不要手动移动鼠标。

### 5) 在配置窗口里点「开始运行」

窗口会关闭，Agent 接管鼠标。启动后有 3 秒倒计时，然后开始自动操作。

## 四、配置窗口里的三项

打开启动器后，窗口里有三个输入框：

| 输入框 | 默认值 | 说明 |
|---|---|---|
| **模型服务地址** | `http://127.0.0.1:1234/v1` | 你的模型服务的 OpenAI 兼容地址。**协议和 `/v1` 都可以省略**，会自动补全 |
| **模型 ID** | `qwen3-vl-30b-a3b-instruct-mlx@5bit` | 必须与服务端实际加载的模型名**完全一致** |
| **API Key** | `lm-studio` | 本地服务随便填（不校验）；用云端 API 时填你自己的 Key |

建议先点 **「测试连接」**：它会去问一次服务，告诉你连不连得上、模型 ID 对不对，
如果不对还会把服务里可用的模型名列出来。

填过之后会保存到同目录的 `config.json`（权限 600，且已在 `.gitignore` 中，
不会被提交到仓库），下次打开窗口自动带出来。

### 三种常见的服务

**A. LM Studio（推荐，本项目实测的组合）**

加载一个 Qwen3-VL 模型（**必须选带 Vision 标记的**）→ 打开 **Local Server**，
端口保持 `1234` → 窗口里「模型 ID」填 LM Studio 界面上显示的那个名字。
不需要 Key，完全离线。

**B. 其他本地 OpenAI 兼容服务（vLLM / Ollama / llama.cpp server）**

只要提供 `/v1/chat/completions` 且支持用 `image_url` 传 base64 图片即可直接接入：

```
模型服务地址：http://127.0.0.1:11434/v1      # 例：Ollama
模型 ID     ：qwen2.5vl:7b                   # 填服务端真实的模型名
```

**C. 云端 API（OpenAI / 通义 / 智谱 等）**

填云端地址 + 模型名 + 你自己的 Key。⚠️ 两点要清楚：

1. **很烧钱** —— 每一轮点砖都要发一张截图（约 510×949 的 JPEG），费用按图片 token 累计；
2. **隐私** —— 你的游戏截图会上传到第三方服务器。

### 对模型的最低要求

1. **必须有视觉能力**（能读图）。纯文本模型完全不可用；
2. **能按固定中文格式回复**。程序用正则从回答里抠坐标（主脚本第 785 行
   `CLICK_LINE_PATTERN` 匹配「点击坐标：x,y」），格式不对就作废重问，
   超过 `RECLICK_ATTEMPTS` 次放弃。指令遵循能力差的模型会疯狂空转；
3. **不需要懂坐标归一化**。每轮程序都会把本地算好的「可点砖块坐标清单」
   写进提示词，模型只需从清单里挑一个（由 `CLICKABLE_HINT_ENABLED` 控制）。
   这也是它比「让模型自己在图里找目标」更稳的原因。

### 硬件参考

| 方案 | 内存 / 显存 | 效果 |
|---|---|---|
| Qwen3-VL-30B-A3B（MLX 5bit，**实测组合**） | ≈ 20.6 GB | 好，本项目验证过 |
| Qwen3-VL-8B 级别 | ≈ 6–10 GB | 能跑，但选砖更容易出错 |
| 云端大模型 | 无要求 | 看模型本身，注意费用与隐私 |

小机器换小模型：**只改窗口里的「模型 ID」即可**。若换模型后发现识别不准，
把主脚本 `MODEL_IMAGE_SCALE`（第 72 行）从 `0.5` 改回 `1.0`，让模型看原尺寸图。

## 五、安全与退出

| 方式 | 说明 |
|---|---|
| **鼠标移到屏幕左上角** | `pyautogui.FAILSAFE` 触发的紧急停止，任何时刻都有效，**最推荐** |
| `Ctrl+C` | 立刻中断程序 |
| 单实例锁 | 防止不小心开两个进程互相抢鼠标。锁文件写在系统临时目录（`$TMPDIR/game_agent.lock`），进程正常退出时自动删除。若提示「已有另一个 Agent 进程在运行」，先关掉旧进程 |

> `pyautogui` 的紧急停止是靠**鼠标位置**判断的：运行期间你一旦把鼠标甩到左上角，
> 程序会立刻抛异常停下。这是特性，不是 bug。

## 六、运行产物：不在本地留下数据

跑起来会截很多图，但**一张都不会留在磁盘上**：

| 东西 | 怎么处理 |
|---|---|
| 每轮截图 | 先写在**系统临时目录**（`$TMPDIR`），该轮请求结束后立刻删除 |
| 分析用的原尺寸图 | 只保留在**内存**里，供遮挡检查等本地逻辑复用，从不落盘 |
| 点击坐标标记图 | 不生成 |
| 结束画面截图 | 不保存 |
| 运行日志 | 不写文件，全部直接打印在终端里 |
| 单实例锁 | 写在系统临时目录，进程正常退出时自动删除 |
| 对局记录 | 不保存 |

唯一可能出现在脚本目录里的文件是启动器的 **`config.json`** —— 你在配置窗口里
填的服务地址、模型 ID 和 Key。它权限是 `600`，也已经写进 `.gitignore`，
不会被提交到仓库。不想留就直接删掉，下次打开窗口会回落成默认值。

## 七、常用参数速查

都在 `Game-agent-fast.py` 顶部，改完**重启 Agent** 才生效。

| 常量 | 行 | 作用 / 什么时候改 |
|---|---|---|
| `REQUEST_TIMEOUT` | 24 | 单次模型请求超时（秒）。模型慢/显存小就调大 |
| `MODEL_TEMPERATURE` / `MODEL_TOP_P` | 34–35 | 模型采样参数。坐标乱飘就再降温度 |
| `MODEL_MAX_TOKENS` | 36 | 输出上限。模型「思考」啰嗦被截断时调大 |
| `CLICK_DELAY` | 42 | 每次点击后的等待（秒）。游戏卡顿就调大 |
| `CHECK_OCCLUSION` | 51 | 遮挡检查：拒绝点被压住的砖（**建议保持 True**） |
| `CLICKABLE_HINT_ENABLED` | 55 | 是否把本地算出的可点坐标清单喂给模型（**建议保持 True**） |
| `RECLICK_ATTEMPTS` | 59 | 模型选到不可点位置后最多重问几次 |
| `MODEL_IMAGE_SCALE` | 72 | 发给模型的图缩放比例。0.5 = 提速 4 倍；模型看不清就调回 1.0 |
| `CROP_TO_GAME_WINDOW` | 77 | 只截游戏窗口（**建议保持 True**，否则砖块太小认不准） |
| `GAME_WINDOW_KEYWORD` | 80 | 窗口标题关键词，找不到窗口时改这里 |
| `LEVEL_END_CONFIRM_ROUNDS` | 97 | 连续几轮判定「本局已结束」才算数（防动画误判） |
| `GRASS_RATIO_MIN` | 101 | 草地占比阈值，用来识别「画面被弹窗盖住」 |
| `RESTART_SCRIPT_NAME` | 138 | 本局结束后要调用的重开脚本文件名 |
| `FORBID_PROPS` | 155 | 禁止使用道具（移出/撤回/洗牌） |
| `FORCED_END_MAX_PER_ROUND` | 158 | 单局最多「主动点砖结束」几次 |
| `STALL_STOP_ROUNDS` | 165 | 空转熔断：卡死这么久（约 2 分钟）就写明原因停机 |
| `TRAY_CAPACITY` | 1024 | 卡槽格数（7）。填满且未三连即失败，别乱改 |

## 八、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 点「测试连接」报连不上 | 服务没启动，或地址填错。本地地址请确认模型服务已打开 OpenAI 兼容接口 |
| 提示「服务里没有模型 xxx」 | 模型 ID 与服务端实际加载的名字不一致。按提示里列出的名字改 |
| 401 / 403 | 用了云端 API 但 Key 没填对 |
| 报缺少依赖 | 按窗口里的提示在终端执行 `pip install -r requirements.txt`，再重新打开启动器 |
| 双击 `run.command` 没反应 / 提示找不到 Python | 装一个自带 tkinter 的 Python 3.11，或改用 `python3 run.py --no-gui` |
| `[警告] 未找到游戏窗口，改用全屏截图` | 窗口标题不含关键词，或窗口被最小化。改 `GAME_WINDOW_KEYWORD`，或把游戏窗口调到前台 |
| 截图全黑 / 只有桌面 | **屏幕录制**权限没给，或没重启终端 |
| 画面正常但游戏毫无反应 | **辅助功能**权限没给 —— 鼠标点击被系统拦了 |
| 点击位置整体偏移 | 外接显示器或改了缩放。脚本已按 `物理像素/逻辑点` 比例换算窗口坐标，若仍偏移请提 issue 并说明屏幕缩放比例与游戏窗口位置 |
| 模型总是回格式错误、反复重问 | 换了指令遵循弱的模型。加大 `MODEL_MAX_TOKENS`，或用第四节 A 方案的 Qwen3-VL |
| 一直在原地空转不点砖 | 通常是「卡槽快满 + 棋盘上确实没有能安全点的砖」。程序会先尝试主动结束本局；连续 `STALL_STOP_ROUNDS` 轮推不动就会熔断停机并写明原因。终端里最后几行会直接告诉你卡在哪 |
| 模型老选到被压住的砖 | 确认 `CLICKABLE_HINT_ENABLED=True` 且 `CHECK_OCCLUSION=True`；也可调低 `MODEL_TEMPERATURE` |
| 提示「已有另一个 Agent 进程在运行」 | 先关掉旧进程。锁文件在系统临时目录（`$TMPDIR/game_agent.lock`），确认旧进程真没了还报错就把它删掉 |
| 窗口里改了配置但没生效 | 配置在点「开始运行」时才写入；改完记得点一下按钮 |
